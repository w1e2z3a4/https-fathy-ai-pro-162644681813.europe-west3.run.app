# 🎨 Fathy AI Pro - تطبيق الذكاء الاصطناعي الإبداعي

تطبيق اندرويد احترافي يستخدم الذكاء الاصطناعي لتحرير الصور وإنشاء محتوى بصري رائع!

🖼️ تعديل الصور | 🎭 إزالة الخلفية | 🖌️ إنشاء صور من النص | 🎬 إنشاء فيديوهات من النص

---

## ✨ المميزات الرئيسية

- 🖼️ **تعديل الصور بالذكاء الاصطناعي** - تحسين جودة وتصحيح الصور
- 🎭 **إزالة الخلفية تلقائياً** - إزالة الخلفية من الصور بنقرة واحدة
- 🖌️ **إنشاء صور من النص** - توليد صور جميلة من الوصف النصي
- 🎬 **إنشاء فيديوهات من النص** - تحويل النصوص إلى فيديوهات احترافية
- 🌙 **دعم المواضيع الفاتحة والغامقة** - واجهة جميلة وسهلة الاستخدام
- 🌍 **دعم اللغة العربية** - تطبيق كامل باللغة العربية
- ⚡ **أداء عالي وسلس** - تطبيق سريع وخفيف الوزن

---

## 📱 المتطلبات

- **نظام التشغيل**: Android 7.0 أو أعلى (API 24+)
- **ذاكرة الجهاز**: 2 GB على الأقل
- **مساحة التخزين**: 100 MB
- **الإنترنت**: اتصال إنترنت مستقر

## 🚀 كيفية التثبيت والتشغيل (الطريقة الأسهل!)

### ✅ الطريقة الأولى: تشغيل مباشر من Android Studio (الأسهل!)

**الخطوة 1**: افتح Android Studio

**الخطوة 2**: اختر `File → Open` واختر مجلد المشروع

**الخطوة 3**: انتظر حتى تنتهي عملية "Gradle Sync" (قد تأخذ 5-10 دقائق)

**الخطوة 4**: اتصل هاتفك بالحاسوب عبر كابل USB

**الخطوة 5**: افعّل وضع المطور على الهاتف:
- ذهب إلى الإعدادات
- بحث عن "رقم الإصدار" (Build Number)
- اضغط عليه 7 مرات
- الآن تم تفعيل وضع المطور

**الخطوة 6**: في Android Studio اضغط على الزر الأخضر ▶️ (Run)

**خلاص!** التطبيق سيتثبت على هاتفك ويعمل تلقائياً! 🎉

---

### ✅ الطريقة الثانية: استخدام Terminal

```bash
# انسخ هذا الأمر في Terminal/Command Prompt

# الخطوة 1: الذهاب إلى مجلد المشروع
cd path/to/your/project

# الخطوة 2: بناء وتشغيل التطبيق
./gradlew installDebugAndRun
```

**انتظر حتى ينتهي!** ✅

---

### ✅ الطريقة الثالثة: بناء ملف APK وتثبيته يدويّاً

**الخطوة 1**: بناء ملف APK
```bash
./gradlew assembleDebug
```

**الخطوة 2**: الملف سيكون هنا:
```
app/build/outputs/apk/debug/app-debug.apk
```

**الخطوة 3**: انسخ الملف إلى هاتفك

**الخطوة 4**: افتح مدير الملفات على الهاتف وثبت الملف

## 📦 بناء النسخة النهائية الاحترافية

عندما تريد إطلاق التطبيق على Google Play:

```bash
./gradlew assembleRelease
```

الملف النهائي سيكون هنا:
```
app/build/outputs/apk/release/app-release.apk
```

## 🔧 حل المشاكل الشائعة

### ❌ المشكلة: "Gradle sync failed"

**✅ الحل**:
```bash
./gradlew clean
./gradlew build
```

---

### ❌ المشكلة: التطبيق لا يعمل على الهاتف

**✅ الحل**:

1. **تأكد من تفعيل وضع المطور**:
   - اذهب لـ Settings (الإعدادات)
   - ابحث عن "About Phone"
   - اضغط على "Build Number" 7 مرات ✨

2. **اسمح بتثبيت من مصادر غير معروفة**:
   - Settings → Security → Unknown Sources ✅

3. **جرب محاكي Android (إذا لم يعمل على الهاتف)**:
   - في Android Studio → AVD Manager

---

### ❌ المشكلة: حجم التطبيق كبير جداً

**✅ الحل**:

عند��ا تبني release (النسخة النهائية)، حجمه سيكون أصغر:
```bash
./gradlew assembleRelease
```

---

### ❌ المشكلة: "app-debug.apk" موجود بس ما يعمل

**✅ الحل**:

```bash
# احذف النسخ القديمة
./gradlew clean

# اعمل build جديد
./gradlew build

# ثبت على الهاتف
./gradlew installDebug
```

## 📤 نشر التطبيق على Google Play (متقدم)

عندما تكون جاهز للإطلاق الفعلي:

**الخطوة 1**: أنشئ حساب مطور على [Google Play Console](https://play.google.com/console)
- الرسوم: 25 دولار (مرة واحدة فقط)

**الخطوة 2**: بناء App Bundle (الملف الاحترافي):
```bash
./gradlew bundleRelease
```

**الخطوة 3**: احفظ ملف `app.aab` من:
```
app/build/outputs/bundle/release/app-release.aab
```

**الخطوة 4**: احمل الملف على Google Play Console

**الخطوة 5**: امل البيانات (الوصف، الصور، إلخ)

**الخطوة 6**: أرسل للنشر ✨
